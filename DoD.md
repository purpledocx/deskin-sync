# Definition of Done

User story is voltooid wanneer:

- De taak heeft duidelijke acceptatiecriteria.
- React-interface en FastAPI endpoint zijn geïmplementeerd, indien nodig voor de taak.
- Invoergegevens worden gevalideerd op de backend.
- Fouten worden duidelijk weergegeven aan de gebruiker.
- Pytest-tests zijn toegevoegd of bijgewerkt.
- Alle tests slagen.
- `npm run lint` loopt zonder fouten.
- Code is gekoppeld aan GitLab Issue.
- Een duidelijke commit is gemaakt.
- Wijziging is doorgegaan via Merge Request.
- Nodig bewijs is opgeslagen: screenshot, testlog of link naar MR.
